# MCServerHost Feedback

The public list of bugs and feature requests for
[MCServerHost](https://www.mcserverhost.com). This repository holds no code.
Each issue is one bug or one idea, so anyone can see what has been reported,
add details and vote for what matters to them.

## Before you post

- Search the [open and closed issues](../../issues?q=is%3Aissue) first. If
  yours is already there, add a thumbs up reaction to its first post, and
  comment only when you have new details.
- Everything here is public. Never post a password, an API key, your email
  address or payment details.
- For help with your own account, a payment or one of your servers,
  [open a support ticket](https://www.mcserverhost.com/support). We can see
  your account there and reply privately.
- If a service seems down, check the
  [status page](https://www.mcserverhost.com/status) first.
- Report a security problem privately, as [SECURITY.md](SECURITY.md)
  describes, and never in a public issue.

## Report a bug

Open a [bug report](../../issues/new?template=bug_report.yml) and fill in the
form. Say what you did, what you expected and what happened instead. A
screenshot or the console output helps us find the cause sooner.

## Request a feature

Open a [feature request](../../issues/new?template=feature_request.yml).
Describe the problem you want solved and how you would like it to work. Post
one idea per issue, so each one can be voted on and closed on its own.

## Vote

Add a thumbs up reaction to the first post of any issue you want. The count
shows us how many people a bug affects or a feature would help. A comment
that only says "+1" sends everyone a notification and adds nothing the
reaction does not.

## Labels

| Label | Meaning |
|---|---|
| `bug` | Something does not work as it should. |
| `feature` | A new feature, or a change to an existing one. |
| `needs triage` | New. The team has not reviewed it yet. |
| `needs info` | We need more details from the person who opened it. |
| `confirmed` | We reproduced the bug. |
| `planned` | We plan to build or fix it. |
| `in progress` | Someone on the team is working on it. |
| `area: ...` | The part of MCServerHost it is about. |

When a fix or a feature is live, we close its issue as completed. When we
decide not to do something, we close the issue as not planned and say why in
a comment.
